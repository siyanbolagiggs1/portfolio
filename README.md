# Khalid Siyanbola, Portfolio

Single page developer portfolio built with Next.js and TypeScript. The design is a port of the plain HTML/CSS/JS
redesign (dark theme, ambient butterflies, scroll reveal, count up stats, tilt and magnetic buttons on pointer
devices, reduced motion support).

## Structure

```
src/app/layout.tsx         Fonts (Inter, JetBrains Mono) and share metadata
src/app/page.tsx           All page content and sections
src/app/globals.css        Styles
src/app/icon.svg           Favicon
src/components/Effects.tsx Client side motion and interactions
public/assets/             Resume PDF and Open Graph image
```

## Local development

```bash
npm install
npm run dev
```
